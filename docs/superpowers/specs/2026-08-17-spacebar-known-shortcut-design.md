# 空格键连续闪卡快捷操作设计

日期：2026-08-17

## 目标

在现有日语五十音闪卡项目中扩展空格键，使用户可以用同一个按键快速完成“显示答案 → 标记认识 → 下一张”的连续练习操作。

## 交互规则

仅在巩固复习、快速测试、新假名主动回忆和混合巩固的闪卡页面生效：

1. 当前答案尚未显示时，按一次空格触发当前页面的“显示答案”。
2. 当前答案已经显示且“认识 / 模糊 / 不认识”按钮可用时，再按一次空格触发“认识”。
3. “认识”仍调用现有评分入口，因此学习记录、权重和下一题跳转与鼠标点击完全一致，不增加另一套数据逻辑。
4. 原有数字键 `1`、`2`、`3` 继续对应认识、模糊、不认识。

## 防止误触

- 监听 `keydown`，忽略 `event.repeat === true`，长按空格不会连续跨过多张卡片。
- 焦点位于输入框或文本区域时不响应。
- 设置对话框或确认对话框打开时不响应。
- 选择题、认识新假名和本组总览页面不使用空格自动选择，避免误答或跳过学习内容。
- 每次有效空格操作调用 `preventDefault()`，避免页面滚动。
- 如果当前既没有显示答案按钮，也没有可用的认识按钮，则不执行任何操作。

## 界面提示

闪卡页面增加简短快捷键提示：`空格：显示答案 / 认识　1：认识　2：模糊　3：不认识`。提示不改变现有按钮布局。

## 实现范围

- 修改 `js/app.js` 中现有键盘监听，根据当前可见按钮决定空格键动作。
- 修改 `index.html`，在闪卡区域增加快捷键提示节点。
- 修改 `styles.css`，使用低强调度的小字样式。
- 修改 `README.md` 中的快捷键说明。
- 增加自动回归测试，确认空格键逻辑包含防重复、显示答案和认识两阶段行为。

## 验证标准

1. 第一张未显示答案时按空格，答案出现且发音流程正常。
2. 再按空格，记录一次“认识”并进入下一张。
3. 长按产生的重复键盘事件不会连续评分。
4. 数字键评分仍正常。
5. 选择题、设置窗口和数字输入框中按空格不会触发闪卡评分。
6. 巩固复习、快速测试、新假名主动回忆和混合巩固均实际验证。
