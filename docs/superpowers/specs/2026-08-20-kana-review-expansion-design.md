# 日语假名与发音规则复习系统重构设计

日期：2026-08-20

## 状态

本设计由用户提供的完整重构规格直接整理，视为已批准设计。执行时不再重复进行产品方案确认；创建或公开推送远程 GitHub 仓库仍需单独确认仓库名和可见性。

## 目标

把现有“从零学习基础五十音”的网站调整为以每日巩固复习为核心的假名与发音规则复习工具，同时：

- 保留原生 HTML、CSS、JavaScript 和纯静态部署。
- 保留现有基础 46 音数据、评分历史和 localStorage。
- 加入浊音、半浊音、拗音、促音和长音。
- 简化新内容学习为顺序浏览，再加入复习池。
- 支持 GitHub Pages 子路径部署，并保留本地启动方式。

## 数据架构

### 学习内容

统一使用 `STUDY_ITEMS`，但允许不同类型拥有不同字段：

- 普通假名：`id`、`category`、`hiragana`、`katakana`、`romaji`、`aliases`、`group`。
- 规则组合：`id`、`category`、`kana`、`romaji`、`focus`、`explanation`、可选 `standardRomaji`。

类别固定为：

1. `basic`：46 个基础音。
2. `dakuten`：20 个浊音。
3. `handakuten`：5 个半浊音。
4. `youon`：33 个常用拗音。
5. `sokuon`：使用完整假名组合的促音示例。
6. `chouon`：使用完整假名组合的长音示例。

基础项目继续用原罗马音作为 `id`，从而直接复用 v3 的记录键。新增项目使用带类别前缀的稳定 ID，避免 `じ/ぢ`、`ず/づ` 等同罗马音发生冲突。

### localStorage v4

保存：

- `version: 4`
- `settings`：上次模式、类别、假名形式、题量、智能/随机模式。
- `courseUntil`：仅为兼容基础 46 音旧课程边界继续保留。
- `categoryStatus`：`not_started`、`browsing`、`browsed`、`joined`。
- `browseProgress`：当前浏览类别、索引和开始时间。
- `records`：每个项目的学习与评分历史。

迁移原则：

- 原基础音记录键和值原样迁移到 v4 后再清洗。
- 原 `courseUntil` 决定基础音的已学习项目；46 时基础类别为 `joined`，1–45 时为 `browsing`，0 时为 `not_started`。
- 新类别只创建状态，不预写虚假学习记录。
- 丢弃所有反应时间和速度字段。
- 每次载入都经过同一清洗过程，结果幂等，不重复累计。

## 主要流程

### 首页与巩固复习

首页标题改为“日语假名复习”，默认模式为“巩固复习”。首页显示六类内容的状态概览和精简设置：

- 内容类别：只允许选择已有可复习项目的类别，可一键全选已学。
- 假名形式：平片混合、仅平假名、仅片假名。
- 题量：20、30、50、100、无限，默认 30。
- 出题：智能复习、均匀随机，默认智能。

设置随评分和页面关闭独立保存。下次进入自动恢复，并自动删除已不可用类别。主页同时提供“只练薄弱项”；没有薄弱项时禁用并说明原因。全部类别加入复习池后显示“全部已学内容 · 30 题”快捷入口。

### 快速过新内容

用户选择一个尚未加入复习池的类别后顺序浏览。页面直接显示字形、罗马音、必要规则说明和发音按钮，只保留“上一张/下一张”。中途退出保存索引。

浏览结束后：

- “加入复习池”：正式标记该类别全部项目为已学习。
- “立即复习”：加入复习池后直接开始该类别的智能复习。

不再保留选择题、主动回忆、混合巩固等强制阶段。

### 自定义测试

允许从所有类别中自由选择内容、假名形式、题量和均匀/智能抽题。测试评分也写入历史；它不是首页默认模式。

### 复习卡和总结

普通假名题面随机显示平或片，答案显示罗马音及两种字形。促音和长音题面显示完整字符串，答案额外突出 `っ/ッ` 或 `ー` 并显示一句规则说明。

评分仍为认识、模糊、不认识。空格第一次显示答案、第二次选择认识；数字键 1/2/3 保留。

总结只显示题数、三类评分、认识率和本轮需要加强项目，并提供“只练这些”“再来一轮”“返回首页”。

## 抽题与薄弱项

智能权重采用可预测规则：

- 认识或无历史：1
- 最近模糊：3
- 最近不认识：5

权重最高不超过 5。记录额外保存 `knownStreak`：认识时加一，模糊/不认识时归零。薄弱项定义为最近结果是模糊/不认识，或曾经存在错误且连续认识未达到 3 次。

抽题记录最近 3 个项目；题池允许时不从最近项目中选择，池太小时逐级放宽，不进入死循环。

## 音频

- 基础 46 音优先播放现有本地 MP3。
- 新增普通假名、促音和长音在缺少本地文件时使用 `speechSynthesis` 的 `ja-JP` 朗读。
- 自动播放受限或所有播放方式失败时仅显示非阻断提示。
- 音频失败不能阻止评分、跳题或保存数据。

## 假名表与学习记录

“五十音表”改为“假名表”，分为基础五十音、浊音/半浊音、拗音、发音规则四个页签。详情显示别名或规则说明，但普通闪卡保持简洁。

学习记录按六类折叠展示，类别摘要包含项目数、已学习、熟练和薄弱数；展开后显示每项认识、模糊、不认识次数，不显示反应时间。

## 静态部署、隐私和本地使用

- 所有网页资源使用相对路径，不使用根路径或本机绝对路径。
- 不引入后端、数据库、登录或重型依赖。
- GitHub Pages 可以从仓库根目录直接部署。
- ES modules 在部分浏览器的 `file://` 下受限，因此保留双击启动脚本作为稳定本地方式，并在 README 说明；站点本身不依赖本地服务。
- `.gitignore` 排除系统、IDE、日志、临时数据和可能的学习记录导出文件。
- 初始化 Git 前扫描账号、Token、Cookie、密钥、本机路径和用户数据。

## 测试范围

自动测试覆盖：

- 六类内容数量与关键日语数据。
- 促音、长音的组合与说明正确性。
- v3 → v4 数据保留、无时间字段、迁移幂等。
- 类别浏览、加入复习池、设置恢复与无效类别清理。
- 1/3/5 权重、最近三题避重、薄弱项恢复规则。
- 20/30/50/100/无限、平/片/混合和类别筛选。
- 音频本地优先与语音合成回退。
- GitHub Pages 相对路径和隐私扫描。

浏览器验证覆盖首页、快速浏览、加入复习池、复习评分、薄弱项、总结、假名表、学习记录、设置恢复和窄屏布局。

## 非目标

不加入 React/Vue、后端、云同步、账号、排行榜、打卡、XP、付费 API 或 AI 功能。远程 GitHub 仓库创建、公开推送和 Pages 开启不在未确认情况下执行。
