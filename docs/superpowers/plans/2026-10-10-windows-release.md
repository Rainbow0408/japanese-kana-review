# Windows v1.0.0 实施计划

用户已批准直接实施和公开发布，无需重复确认。

- [x] 桌面：新增Electron main/协议与路径测试，package/lock、builder配置、安装/portable、草稿Release工作流。验证安全设置、ES模块/MIME、路径越界、持久来源及默认数据路径。
- [x] 备份：失败测试先行，校验1MiB/版本/字段，导出、预览确认导入、前状态恢复、持久写失败回滚；设置UI和当前电脑文案。
- [x] 音频：官方VOICEVOX生成器与资料置tmp；生成/核对128 WAV和manifest、读法修正、音频测试与来源说明，不分发引擎。
- [x] 整合：Windows ICO、MIT/第三方说明、下载README、缓存版本同步、现有音频测试按新契约调整、打包白名单及忽略规则。
- [ ] 验证：全部自动测试、源码复核、桌面UI与无网络/无系统声音成品自检、安装及免安装profile隔离、备份迁移、重启与替换持久记录、安装/卸载留存。
- [ ] 发布：明确选择代码/音频/配置文件提交到桌面分支，推送并附PR；审核整合到main；tag生成草稿，验收后发布，匿名验证资产与校验值。

各代理按互斥文件所有权协作，主任务负责整合与发布；本地用户学习记录不用于测试。QA profile仅通过任务控制的KANA_TEST_DATA_DIR环境变量隔离，生产默认路径稳定。
