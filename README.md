# 日语假名闪卡

一个无需登录、无需后端的纯前端日语假名复习工具。核心目标是快速进行“看到假名或假名组合 → 想起罗马音”的闪卡复习。

## 功能

- 基础五十音
- 浊音与半浊音
- 常用拗音
- 促音组合练习
- 长音组合练习
- 智能闪卡复习
- 薄弱项专项复习
- 快速浏览新内容
- 自定义测试
- 本地学习记录
- 本地音频与日语语音合成回退
- 无需登录、无后端、无付费 API

## 本地使用

最稳定的方式是双击项目根目录里的 `启动学习器.bat`，它会启动一个临时静态网页服务并自动打开学习页面。

也可以尝试直接双击 `index.html`。由于项目使用浏览器 ES modules，部分浏览器会限制 `file://` 页面加载模块或保存数据；遇到空白页时请改用启动脚本。关闭学习页面后，可关闭脚本对应的命令窗口。

学习数据不会写入项目文件，而是保存在浏览器的 `localStorage` 中。

## 三种模式

- 巩固复习：默认模式，从已经加入复习池的类别中抽题；智能模式会提高模糊和不认识内容的出现概率。
- 快速过新内容：按顺序浏览一个类别，完成后可加入复习池或立即开始复习。
- 自定义测试：自行选择类别、平片假名形式、题量和出题方式。

闪卡支持快捷键：

- `Space`：显示答案；答案显示后再次按下会选择“认识”并进入下一张。
- `1`：认识。
- `2`：模糊。
- `3`：不认识。

## GitHub Pages 部署

项目是纯静态文件，资源均使用相对路径，可直接部署在仓库子路径中。

1. 把项目文件上传到 GitHub 仓库。
2. 打开仓库的 **Settings**。
3. 在左侧选择 **Pages**。
4. 在 **Build and deployment** 中选择 **Deploy from a branch**。
5. Branch 选择 `main`。
6. Folder 选择 `/(root)`。
7. 点击 **Save**。

发布完成后，GitHub 会在 Pages 设置页显示访问地址。请检查首页样式、闪卡脚本和基础音频是否正常加载。

## 数据与隐私说明

所有学习记录都保存在当前浏览器的 `localStorage`：

- 更换浏览器或设备不会自动同步。
- 清除浏览器网站数据会删除学习记录。
- GitHub 和 GitHub Pages 不会替你保存学习记录。
- 项目目录和 Git 提交中不包含你的浏览器学习数据。

旧版基础五十音数据会自动迁移到 v4，并保留课程进度、认识、模糊、不认识、首次学习时间等历史。反应时间和速度字段不会继续保存。

## 音频

基础 46 音优先使用 `assets/audio` 中的本地 MP3。新增的浊音、半浊音、拗音、促音和长音在没有本地录音时，会尝试使用浏览器日语语音合成。播放失败不会阻止答题或保存记录。

## 项目结构

```text
index.html          页面结构
styles.css          桌面与窄屏界面样式
js/data.js          六类假名与发音规则数据
js/storage.js       v4 本地数据与旧版迁移
js/flashcards.js    类别筛选、智能抽题和总结
js/new-learning.js  快速浏览辅助逻辑
js/audio.js         本地音频与语音合成回退
js/keyboard.js      闪卡快捷键状态判断
js/app.js           页面和完整学习流程
assets/audio/       基础五十音本地发音
tests/              Node 自动测试
```

## 技术说明

项目只使用原生 HTML、CSS 和 JavaScript，不需要安装 npm 依赖，也不需要数据库或服务器端程序。
